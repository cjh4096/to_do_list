# To Do List + 날씨 예보

날짜별로 할 일을 관리하는 tkinter 데스크톱 앱에 **OpenWeatherMap 날씨 예보 API**를 연동한 프로젝트입니다.
선택한 날짜의 날씨를 함께 보여주고, 비·눈 예보가 있으면 우산 알림을 띄웁니다.

## 주요 기능
- 날짜별 할 일 추가/삭제, 체크 시 취소선, 자동 저장(`todos.json`)
- 5분 단위 시간 / 종일 / 여러 날(기간) 일정
- 부팅 시 자동 실행 설정 (Windows)
- **[신규]** 선택한 날짜의 날씨(아이콘, 설명, 최저~최고 기온) 표시
- **[신규]** 비/눈 예보 + 할 일이 있는 날 우산 알림, 🔄 버튼으로 예보 새로고침

## 실행 방법
1. [uv](https://docs.astral.sh/uv/) 설치 후 저장소를 받습니다.
   ```bash
   git clone <저장소 URL>
   cd <저장소 폴더>
   ```
2. `.env.example`을 복사해 `.env` 파일을 만들고 키를 넣습니다. (아래 "API 키 설정" 참고)
3. 실행합니다. 외부 패키지가 없어 별도 설치 없이 uv가 Python 환경을 맞춰줍니다.
   ```bash
   uv run main.py
   ```

## API 키 설정
프로젝트 폴더에 `.env` 파일을 만들고 아래 형식으로 작성합니다.
```
OPENWEATHER_API_KEY=발급받은_API_키
WEATHER_CITY=Suwon,KR
```
- `OPENWEATHER_API_KEY`: [openweathermap.org](https://openweathermap.org) 가입 후 *My API keys*에서 발급 (발급 직후 활성화까지 최대 몇 시간 걸릴 수 있음)
- `WEATHER_CITY`: `도시명,국가코드` 형식 (생략 시 `Seoul,KR`)
- `.env`는 `.gitignore`에 포함되어 저장소에 올라가지 않습니다. 과제용 키는 icampus로 별도 제출했습니다.

## 코드 설명

### main.py
- **`TaskManager`**: 할 일 데이터를 리스트(딕셔너리)로 관리하고 `todos.json`에 저장/불러오기합니다. 날짜별 조회 시 시작일~종료일 범위에 포함된 일정을 찾고, 종일 일정을 먼저, 나머지는 시간순으로 정렬합니다. 시작 프로그램 폴더에 `.vbs` 파일을 만들어 부팅 시 자동 실행을 설정합니다.
- **`AddTaskDialog`**: 할 일 추가 창입니다. 제목, 날짜(YYYY-MM-DD), 기간/종일/시간을 입력받아 형식을 검사한 뒤 콜백으로 전달합니다.
- **`TodoApp`**: 메인 창입니다. 선택 날짜 기준 앞뒤 7일 버튼, 할 일 목록, 날씨 라벨을 그립니다. 화면은 `refresh()` 하나로 다시 그려지며, 날짜 이동·체크·추가·삭제 후 항상 호출됩니다.
  - `_load_weather()`: 날씨 API를 **별도 스레드**에서 호출합니다. 네트워크 요청 중에도 창이 멈추지 않게 하기 위함입니다.
  - `_poll_weather()`: tkinter 화면은 메인 스레드에서만 바꿔야 하므로, `after()`로 0.3초마다 스레드 결과를 확인하고 도착하면 `refresh()`합니다.
  - `_weather_text()`: 선택 날짜의 예보로 표시 문구를 만들고, 비/눈 예보가 있고 할 일이 있으면 우산 알림을 붙입니다.

### weather.py
- **`load_env()`**: `.env`의 `KEY=VALUE` 줄을 읽어 환경변수로 등록합니다. 외부 패키지(python-dotenv) 없이 직접 구현해 5주차의 "표준 라이브러리만 사용" 조건을 유지했습니다.
- **`WeatherClient.fetch_daily()`**: `urllib`로 Forecast API를 호출합니다. 상태 코드에 따라 `WeatherError`로 사용자용 메시지를 만들어 던집니다(키 없음, 401 키 오류, 404 도시 오류, 네트워크 오류).
- **`_summarize()`**: API는 3시간 간격 예보 약 40개를 UTC 시간으로 줍니다. 응답의 `city.timezone`(초)으로 현지 시간으로 바꾼 뒤 날짜별로 묶어, 최저/최고 기온, 정오에 가장 가까운 예보를 대표 날씨로, 하루 중 비·눈 예보가 하나라도 있으면 `rain=True`로 정리합니다.

### 데이터 흐름
```
앱 시작/🔄 클릭 → 스레드에서 fetch_daily() → API 응답(JSON)
→ _summarize()로 날짜별 요약 → _poll_weather()가 결과 수신 → refresh()에서 선택 날짜 날씨 표시
```

## 예외 처리와 한계
- 키가 없거나 인터넷이 끊겨도 할 일 기능은 그대로 동작하고, 날씨 줄에 원인만 안내합니다.
- 무료 API 특성상 예보는 오늘부터 약 5일까지만 제공되며, 그 이후 날짜는 "예보 범위 밖"으로 표시합니다.
- 날씨 데이터는 앱 실행 중 메모리에만 보관하고 저장하지 않습니다.
